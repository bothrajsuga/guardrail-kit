# Security policy

Version 0.1.x receives security fixes while it is the latest minor release. Please report vulnerabilities privately through the repository host's private vulnerability-reporting feature once a repository is configured. Do not include secrets, production SQL, credentials, or personal data in a report. No security-report email is listed because the project has not provided one.

This package is defense in depth and makes no guarantee of complete AI-agent or database security. See `docs/security.md`.
