# Roadmap

## v0.2.0

Planned PII detection and masking for common email addresses and phone numbers, configurable patterns and masking, explicit input/output inspection, privacy-preserving audit events, and false-positive/false-negative coverage. Detection limitations will be documented.

## Later

Optional LangChain and LangGraph adapters, more framework integrations based on demand, and additional explicitly tested SQL dialects. None is implemented in v0.1.0.
